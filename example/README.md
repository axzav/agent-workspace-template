# example/ — заполненный пример: проект «Bookly» (сервис бронирования)

Вымышленный проект, показывающий, **как выглядят заполненные файлы** слоя агента. Здесь лежат только файлы,
содержание которых отличается от `skeleton/` (скрипты, шимы команд, промпты, шаблоны задач — те же, что в скелетоне).
Кода сервисов нет: их `AGENTS.md` — в `repos/<сервис>/`.

Используется промптом `SEED.md` как эталон глубины и тона. Показаны оба режима трекера: локальные задачи и задача,
привязанная к удалённому трекеру (`remote: BOOK-412`, публикуется `trk.sh publish`), эпик-папка с контекстом и
задачами внутри (в т.ч. закрытой, которая остаётся на месте), задача-папка с контекстом (`BKL-0002-…/BKL-0002-….md`).

Bookly: гости бронируют номера у хостов; backend (Symfony) — API и бизнес-логика; frontend (React) — UI;
realtime (Node) — уведомления по WebSocket; infra — compose и деплой.
