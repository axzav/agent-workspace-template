## Контекст / Проблема
Рейтинг — то, ради чего эпик BOOK-430 делается: он должен появиться в поиске и карточке объекта и совпадать с
тем, что гости реально поставили. Считать «на лету» по всем отзывам при каждом показе поиска нельзя —
поиск и так самый тяжёлый запрос, поэтому рейтинг хранится готовым и пересчитывается по событиям отзывов.

## Что делаем
- Рейтинг объекта = среднее арифметическое оценок по опубликованным отзывам, с одним знаком после запятой.
- Показывается, если отзывов ≥ 3; иначе в поиске и карточке — бейдж «Новый объект».
- Обновляется не позже чем через минуту после публикации, правки или скрытия отзыва.
- В карточке рядом с рейтингом — количество отзывов.

| Отзывов | Оценки | В карточке |
|---|---|---|
| 0 | — | «Новый объект» |
| 2 | 5, 1 | «Новый объект» (порог не достигнут) |
| 3 | 5, 4, 4 | ★ 4.3 · 3 отзыва |
| 3, один отредактирован 4→2 | 5, 2, 4 | ★ 3.7 · 3 отзыва |

## Не входит
- Сортировка поиска по рейтингу (отдельная задача после релиза).
- Взвешивание по давности отзыва — обсуждали, отложили до появления данных.

## Критерии готовности
- [ ] Рейтинг в карточке и в выдаче поиска совпадает со средним по опубликованным отзывам (проверка на 5 объектах stage).
- [ ] У объекта с < 3 отзывами — «Новый объект», с 3 — звёзды появляются без ручных действий.
- [ ] Правка отзыва меняет рейтинг в течение минуты.
- [ ] Поиск не стал медленнее: p95 `GET /api/search` на stage в пределах текущих 300 мс.
- [ ] Есть пересчёт рейтинга по всем объектам для восстановления после сбоя.
