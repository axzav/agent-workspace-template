## Контекст / Проблема
Хост, получивший несправедливый отзыв, сейчас может только написать в поддержку. Публичный ответ снимает
большую часть таких обращений и даёт будущим гостям вторую точку зрения.

## Что делаем
Под отзывом хост объекта видит «Ответить»; ответ — текст до 1000 символов, один раз, без правки — чтобы не превращалось в переписку. Ответ
показывается под отзывом всем. Гостю уходит push «Хост ответил на ваш отзыв».

## Критерии готовности
- [ ] Хост объекта может ответить один раз; второй ответ → 409; чужой хост → 403.
- [ ] Ответ виден под отзывом в карточке объекта.
- [ ] Гость получает push один раз.
