# Отмена бронирования и возвраты

Источник истины — `backend/src/Booking/Domain/CancellationPolicy.php`. Сверено с кодом на 2026-08-20 (коммит `a1b2c3d`).

| UC | Правило |
|---|---|
| UC-020 | Гость может отменить бронь в статусе `confirmed` до check-in. После check-in — только через поддержку. |
| UC-021 | Политика `flexible`: полный возврат при отмене ≥ 24 ч до check-in; иначе удерживается первая ночь. |
| UC-022 | Политика `strict`: возврат 50 % при отмене ≥ 7 дней; иначе 0 %. Сервисный сбор не возвращается никогда. |
| UC-023 | Хост может отменить `confirmed` бронь — гость получает 100 % + купон 10 %; хосту начисляется штраф (см. `HostPenalty`). |
| UC-024 | Отмена публикует `booking.cancelled` с полем `refund.amount`; платёж возвращается воркером `RefundWorker` асинхронно. |

Расхождение со старой спекой: в спеке 2025 года `strict` давал 30 % — в коде 50 %, верить коду.
