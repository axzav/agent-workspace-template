# Контракты между сервисами
`events/<name>.schema.json` + `events/<name>.example.json`. Публикует backend; потребляют воркеры backend и realtime.
Правило синхронности: контракт, обе стороны и фикстура — в одном изменении; фикстура монтируется в контейнеры
read-only по пути `/contracts` и используется контракт-тестами обеих сторон.
