# workspace/ — слой агента проекта {{PROJECT}}

| Папка | Что | Природа |
|---|---|---|
| `docs/` | Знания о продукте и системе | вневременное: «как есть сейчас», не лог |
| `tracker/` | Задачи (в remote-режиме — кэш удалённого трекера) + работа над ними | временно́е: берётся, делается, уезжает в `done/` |
| `prompts/` | Тела промптов для `.claude/commands/*` | инструментарий |
| `bin/` | Скрипты по всем репо и по трекеру | инструментарий |
| `memory/` | Память агента | только факты о коде и датированные снимки; правила — в `AGENTS.md` |

Лестница чтения — в `AGENTS.md` корня. Все пути — от корня проекта.
