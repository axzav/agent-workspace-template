# Оценка задачи
Оценка в SP/часах по коду затронутых repos; результат — в `estimation:` frontmatter задачи (только эта команда его
заполняет; при заведении задачи оценка не делается). Калибровка — таблица фактов в `workspace/tracker/notes/estimate-history.md`
(задача, оценка, факт). Вывод: оценка, разброс, что увеличивает риск. Оценка персональная под {{кто делает}}.
