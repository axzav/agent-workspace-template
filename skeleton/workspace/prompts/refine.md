# /refine [текст] — входящие → задачи и правки
Вход: аргумент (текст, лог, список находок) или, без аргумента, папки `workspace/tracker/notes/`,
`workspace/tracker/proposals/`, `workspace/tracker/friction/` (что где и форматы — `workspace/tracker/AGENTS.md`,
«Входящие»).
1. Классифицировать каждую находку: баг / долг / идея / трение / не наше. Для бага — воспроизводимость и затронутые
   repos. Много находок (≥ 8) — верификацию раздать Explore-подагентам по одной. Ничего не чинить в коде.
2. Заметка, предложение, баг, идея: дубликат существующей задачи → дописать туда; иначе задача по правилам
   `/tracker-add` — проблему, варианты и числа перенести целиком, не сокращая пересказом; размер, repos, при нужде
   эпик. Условие «когда брать» не наступило — файл в `proposals/` по формату, не задача.
3. Трение: правка инструкции, дока или скрипта — сделать правкой и показать дифф, не задачей; задача — только если
   нужен код или решение человека. Первыми — файлы с большим числом «Случаев».
4. Обработанные файлы `proposals/` и `friction/` удалить, заметки — пометить обработанными. Сводку показать до
   записи, дождаться «ок».
