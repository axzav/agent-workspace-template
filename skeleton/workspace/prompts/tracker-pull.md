# /tracker-pull <KEY> — подтянуть задачу из удалённого трекера
1. Получить задачу `<KEY>` через транспорт из `project.yaml: tracker.remote_transport` (описание, вложения, комментарии,
   связи: родитель, блокеры).
2. Файла нет — создать `<KEY>-slug.md` в `workspace/tracker/tasks/` (или в папке эпика, если родитель уже заведён
   локально) по `TEMPLATE-task.md`: `id`/`remote` = ключ, описание разложить по разделам постановки, перенося
   формулировки, не пересказывая. `created` — дата создания в трекере, `remote_synced` = `trk.sh now`.
3. Файл есть — показать diff описания трекера против постановки; расхождения не затирать молча, спросить, кто истина.
4. Вложения — в `context/` папки задачи (`trk.sh promote`, если файл; вложения — тогда же `INDEX.md`); транспорт не
   сохраняет файлы — текстовая копия `context/attachment-<id>-<slug>.md`. Комментарии — в `comments.md` по формату
   `workspace/tracker/REMOTE.md`: только новые (`id > last_remote_comment`), обновить шапку.
5. Показать, что изменилось; ничего в трекер не писать.
