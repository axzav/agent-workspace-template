# /triage — разбор находок
Аргумент — текст/лог/список проблем. Классифицировать: баг / долг / идея / не наше. Для бага — воспроизводимость
и затронутые repos. Много находок (≥8) — верификацию раздать Explore-подагентам по одной. Результат — задачи
(через правила `/refine`) или `proposals/`. Ничего не чинить в рамках триажа.
