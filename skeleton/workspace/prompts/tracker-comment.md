# /tracker-comment <ID> <текст> — оставить комментарий к задаче
1. Дописать запись в `comments.md` папки задачи (`trk.sh promote`, если задача — файл; формат —
   `workspace/tracker/AGENTS.md`): время `trk.sh now`, автор — `git config user.name`, источник `локально`.
2. Задача привязана к трекеру (`remote:` заполнен) и в аргументах не сказано «только локально» — показать текст,
   после подтверждения отправить через `tracker.remote_transport`, дописать в запись «→ Отправлен в трекер #<id>».
   В тексте — ни путей, ни имён из личного слоя (правило корня).
3. Комментарий меняет постановку — предложить правку «Что делаем» / «Открытые вопросы» отдельным шагом.
