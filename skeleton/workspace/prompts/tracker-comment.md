# /tracker-comment <ID> <текст> — оставить комментарий к задаче
1. Дописать запись в `comments.md` папки задачи (`trk.sh promote`, если задача — файл; создать файл по формату
   из `workspace/tracker/AGENTS.md`): время `trk.sh now`, автор — `git config user.name`, источник `локально`.
2. Если задача привязана к трекеру (`remote:` заполнен) и в аргументах не сказано «только локально» — показать текст,
   после подтверждения отправить через `tracker.remote_transport`, дописать в запись «→ отправлен в трекер #<id>».
3. Если комментарий меняет постановку — предложить правку «Что делаем» / «Открытые вопросы» отдельным шагом.
