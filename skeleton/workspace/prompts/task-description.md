# Описание задачи для удалённого трекера (режим remote)
Эталон формата — {{путь к эталонной задаче}}. Главный файл задачи пишется по `workspace/tracker/TEMPLATE-task.md`
одинаково для любого режима: Контекст / Что делаем / Не входит / Критерии готовности — продуктовым языком, без
путей, классов и локальных ссылок; id задач — голыми. Прогнать `workspace/bin/tracker/trk.sh publish <ID> --diff`,
показать diff, после публикации проставить `remote_synced` из `trk.sh now`.
