# Память агента — индекс
Одна строка на файл: дефис, markdown-ссылка на файл памяти, тире, суть. Здесь — только факты о коде, которых нет
в доках, и датированные снимки. Воспроизводимые правила — в `AGENTS.md` корня или `<сервис>/CLAUDE.local.md`,
не в память; протухший снимок — удалять, а не уточнять.
