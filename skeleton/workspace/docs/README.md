# docs/ — индекс знаний

| Папка/файл | Владеет | Когда читать |
|---|---|---|
| `knowledgebase/` | бизнес-правила, доменная модель, UC-сценарии | перед изменением поведения продукта |
| `contracts/` | контракты между сервисами (REST/события/очереди), схемы + фикстуры | при правке границ сервисов |
| `dev/` | как разрабатывать: командный стек, исключения «на хосте», окружения, креды dev | при запуске/диагностике |
| `raw/` | сырьё: треды, тикеты, спеки «как есть»; **устаревает**, истина — код | только как источник для `features/` |
| `features/` | выжимки по фичам из `raw/` + кода, с указанием коммитов сверки | при работе над фичей |

## Матрица «что изменилось → куда писать»
| Изменилось | Править |
|---|---|
| Бизнес-правило, поведение | `knowledgebase/` (+ код — источник истины) |
| Контракт между сервисами | `contracts/` + фикстуры, в обоих сервисах |
| Способ запуска/порты/команды (командный) | `dev/` и `project.yaml`; личный — `CLAUDE.local.md` |
| Состав сервисов, связи | `AGENTS.md` корня + `project.yaml` |
| Внутренности сервиса | `<сервис>/AGENTS.md` и его `docs/` |
| Ход работы, решения по задаче | `tracker/` (задача/эпик), **не сюда** |

Правила: текущее состояние, а не история; id задач по докам не расставлять; при расхождении с кодом — верить коду
и править док.
