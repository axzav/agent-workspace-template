# SEED — засев слоя агента в проекте (промпт для агента)

Ты работаешь из корня проекта, в котором лежат репозитории сервисов и клон `agent-workspace-template/`.
Задача — заполнить слой агента (скелетон уже развёрнут `init.sh`; если нет — запусти
`agent-workspace-template/init.sh <имя> <ПРЕФИКС> .`). Эталон глубины и тона — `agent-workspace-template/example/`
(читается только на фазе засева и по явной просьбе; в повседневной работе хватает шаблонов и правил скелетона)
(проект Bookly): читай его файлы **перед** тем, как писать соответствующие файлы проекта.

**Не генерируй базу знаний (`workspace/docs/knowledgebase`, `features`, `contracts`) — это отдельная команда
(`SEED-DOCS.md`).** Здесь — структура, карта, манифест, правила, `AGENTS.md` сервисов.

## Шаги
1. **Инвентаризация.** Для каждой папки в корне с `.git`: README, Makefile/Taskfile, compose, `.env*.example`,
   существующие `CLAUDE.md`/`AGENTS.md`/`docs/`, роутинг/nginx, способ auth между сервисами. Ничего не запускай —
   только читай. Зафиксируй: стек и версии, базовую ветку (`git -C <repo> symbolic-ref refs/remotes/origin/HEAD`),
   формат коммитов (по `git -C <repo> log --oneline -30`), порты, адреса.
2. **`project.yaml`** — заполни `repos[]`, `run.team`, `ports`, `tracker` (спроси режим и префикс удалённого трекера,
   если не очевидно). Пример — `example/project.yaml`. В корневой `.ignore` — строка `!/<путь>/` на каждый сервис
   (без этого Grep/Glob из корня не видят их код; проверка — `check/searchignore.sh`).
3. **`AGENTS.md` корня** — по `example/AGENTS.md`: о продукте (из README), таблица сервисов, схема связей,
   командный запуск, правила. Существующие корневые `CLAUDE.md`/карты — источник, перенеси и удали дубли.
   Устаревшие tracked-файлы инструкций в репо — перечисли явно.
4. **`workspace/docs/dev/README.md`** — командный способ запуска, исключения «на хосте», окружения (без секретов).
5. **`AGENTS.md` каждого сервиса** — черновик по `repo-template/AGENTS.md` и `example/repos/*/AGENTS.md`. Если в репо
   уже есть актуальный `CLAUDE.md`/`AGENTS.md` — не переписывай, предложи только `CLAUDE.md`=`@AGENTS.md` и
   `gitignore.snippet`. Черновики **показать**, в чужие репо не коммитить.
6. **Личное.** `CLAUDE.local.md` не заполняй (это делает человек); если в корне/репо есть личные файлы
   (`CLAUDE.local.md`, `Makefile.local`, `_docs/`) — проверь `check/gitignore.sh`, предложи перенос в `local/`.
7. **Трекер.** Есть удалённый трекер — `project.yaml: tracker.mode: remote`, `task_prefix` = его очередь (id задачи =
   ключ трекера), `local_prefix` — для задач без тикета. Живые задачи перенести через `/tracker-pull <KEY>` по списку,
   согласованному с пользователем; старые локальные заметки по задачам — в `context/` соответствующих папок.
8. **Проверка.** `workspace/bin/check/all.sh` до зелёного. Отчёт: что заполнено, что осталось в `{{…}}`, вопросы.

## Правила
- Все пути — от корня проекта; в `AGENTS.md` сервисов — от корня сервиса.
- Пиши текущее состояние, не историю. Не выдумывай: чего нет в коде/README — оставь `{{…}}` и спроси.
- Секреты не копировать; в `.mcp.json` — только `${VAR}`.
- Не запускать стек, тесты, установку зависимостей.
